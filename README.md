# Japanese Character Learning Website

A simple, interactive web app to help you learn hiragana, katakana, and basic kanji through flashcard-style quizzes.

## Features

- **Three Study Modes**: Switch between hiragana, katakana, and kanji
- **Interactive Quizzes**: Type the phonetic reading to validate your knowledge
- **Progress Tracking**: Score, streak, and completion progress
- **Flexible Input**: Accepts both romaji and Japanese character input
- **Helpful Hints**: Toggle romaji hints when needed
- **Mobile Responsive**: Works on phones, tablets, and desktops

## How to Use

1. **Select a Mode** - Choose hiragana (ひらがな), katakana (カタカナ), or kanji (漢字) at the top
2. **Study the Character** - Look at the displayed character
3. **Type the Reading** - Enter the romaji pronunciation (e.g., "a", "shi", "ichi")
4. **Check Answer** - Press Enter or click "Check" to validate
5. **Repeat** - Move through all characters in the set

### Tips
- ✅ Multiple valid answers are accepted (e.g., "shi" or "si" for し/シ)
- 🔥 Build streaks for better retention
- 📝 Toggle "Show Romaji Hints" when learning new characters
- 🌐 Enable "Allow Japanese Input" to type in Japanese characters

## Hosting on GitHub Pages

### Step 1: Create Repository
1. Go to github.com and create a new repository
2. Name it something like `japanese-learning` or `kanji-quiz`
3. Keep it public or private (your choice)

### Step 2: Upload Files
Upload these four files to your repository:
- `index.html`
- `styles.css`
- `data.js`
- `app.js`
- `README.md` (this file)

### Step 3: Enable GitHub Pages
1. Go to repository **Settings** tab
2. Click **Pages** in the left sidebar
3. Under **Source**, select `main` (or `master`) branch
4. Click **Save**
5. Wait 1-2 minutes, then visit your site at: `https://[your-username].github.io/[repo-name]/`

### Step 4: Customize (Optional)
Edit the `data.js` file to:
- Add more kanji characters
- Adjust difficulty levels
- Include additional reading variations
- Add furigana/hiragana readings for kanji
